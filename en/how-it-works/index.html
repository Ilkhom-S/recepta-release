The data stays with you, and work does not stop without a connection

The application runs on your own computers and phones; every record is made locally and syncs when a connection appears; the data is encrypted; the backup is a file that opens on another computer.

Works without a connection, syncs when one appears

  1. Every device records on itself
  2. Sync with the server - by itself or by a button
  3. Other employees' devices receive the changes on their next sync

No connection - work does not stop

A connection is needed to exchange data - and nowhere else.

  • Entry, reports and printing work without a connection - in the office and in the field alike
  • A manager's phone accumulates records and hands them over when a connection appears
  • Speed does not depend on the channel

Sync

When there is a connection - by itself; when you need it now - by the “Sync” button.

  • What travels: goods receipts, deliveries, sales reports, visits, dictionaries - everything recorded on this device, documents together with the records
  • Others' changes arrive on the device's next sync
  • The data stays yours: the database is encrypted, sign-in by PIN and fingerprint, the money ledger is never rewritten, the backup is a file

What it runs on

One product, the same data.

  • Windows and macOS - the office
  • Android and iOS - the field
  • The interface is in Russian, search and sorting handle Cyrillic correctly; English is available
  • Light and dark theme

Two editions

One application; the editions differ by what they add.

  • Single device

    ready

    One computer, no sync - everything described above.

  • Sync

    in development

    A server, the managers' phones, several devices, roles. The server belongs to the vendor or to you.

Updates

The application updates itself on Windows and macOS - never silently: before an update you see what changed and how large the download is. For a computer that is kept off the network, the installer can be carried on a USB stick; it carries the same signature.
