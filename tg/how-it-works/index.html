Додаҳо назди шумо мемонанд, ва кор бе алоқа қатъ намешавад

Барнома дар компютерҳо ва телефонҳои худи шумо кор мекунад; ҳар сабт дар ҷои худ карда мешавад ва вақте алоқа пайдо мешавад, ҳамоҳанг мешавад; додаҳо рамзгузорӣ шудаанд; нусхаи эҳтиётӣ - дар файле, ки дар компютери дигар кушода мешавад.

Бе алоқа кор мекунад, вақте алоқа пайдо мешавад, ҳамоҳанг мешавад

  1. Ҳар дастгоҳ дар худаш сабт мекунад
  2. Ҳамоҳангсозӣ бо сервер - худаш ё бо тугма
  3. Дастгоҳҳои кормандони дигар тағйиротро ҳангоми ҳамоҳангсозии навбатӣ мегиранд

Бе алоқа - кор қатъ намешавад

Алоқа барои мубодилаи додаҳо лозим аст - дигар ҳеҷ ҷо.

  • Воридкунӣ, ҳисоботҳо ва чоп бе алоқа кор мекунанд - дар идора ва дар саҳро як хел
  • Телефони менеҷер сабтҳоро ҷамъ мекунад ва вақте алоқа пайдо шавад, онҳоро медиҳад
  • Суръат аз канал вобаста нест

Ҳамоҳангсозӣ

Вақте алоқа ҳаст - худаш; вақте ҳозир лозим аст - бо тугмаи «Ҳамоҳангсозӣ».

  • Чӣ меравад: воридот, таҳвилҳо, ҳисоботи фурӯш, боздидҳо, маълумотномаҳо - ҳама чизе, ки дар ин дастгоҳ сабт шудааст, ҳуҷҷатҳо якҷоя бо сабтҳо
  • Тағйироти дигарон ҳангоми ҳамоҳангсозии навбатии дастгоҳ меоянд
  • Додаҳо аз они шумо мемонанд: пойгоҳ рамзгузорӣ шудааст, вуруд бо PIN ва изи ангушт, дафтари пул аз нав навишта намешавад, нусхаи эҳтиётӣ - дар файл

Дар чӣ кор мекунад

Як маҳсулот, ҳамон додаҳо.

  • Windows ва macOS - идора
  • Android ва iOS - саҳро
  • Интерфейс ба забони русӣ, ҷустуҷӯ ва мураттабсозӣ ҳарфҳои русиро дуруст мефаҳманд; англисӣ ҳаст
  • Мавзӯи равшан ва торик

Ду таҳрир

Як барнома; таҳрирҳо бо он фарқ мекунанд, ки чӣ илова мекунанд.

  • Як дастгоҳ

    тайёр

    Як компютер, бе ҳамоҳангсозӣ - ҳама чизи дар боло тасвиршуда.

  • Ҳамоҳангсозӣ

    дар таҳия

    Сервер, телефонҳои менеҷерон, якчанд дастгоҳ, нақшҳо. Сервер ба таъминкунанда ё ба шумо тааллуқ дорад.

Навсозиҳо

Барнома дар Windows ва macOS худаш нав мешавад - ҳеҷ гоҳ хомӯшона: пеш аз навсозӣ дида мешавад, ки чӣ тағйир ёфт ва боргирӣ чӣ қадар вазн дорад. Барои компютере, ки ба шабака пайваст намекунанд, насбкунандаро дар флешка овардан мумкин аст; имзои он ҳамон аст.
